Docking: a dock's address can be changed without undocking (CHANGE ADDRESS on the dock row, `PATCH /api/docking/<id>`): the dock keeps its name and secret and the next call goes to the new address. An address may now end with `/r/<room>`, so a dock in a room other than main can be reached from another station. A dock that the other station does not know at its address now says so (the dock may be in another room there, or was removed) instead of "refused". Rooms of one machine can dock with each other: the Station name can be set per room (it was one name for every room), and the Address box keeps the room (`/r/<room>`) when it suggests a network address.
