- **Image verification, stricter now that releases are attested.** For `ghcr.io/ulm0/gonogo` from 0.8.0 on, a missing attestation is a failure with no override (before it could be confirmed by hand), and the attestation must come from the tag of the release being installed (`--source-ref refs/tags/v<version>`), so a run of the image workflow from a branch cannot produce an image that verifies. "Gonogo could not check" (no GitHub login for `gh`) is its own answer now, apart from "no attestation": its own message and its own key in the update strip (**Update anyway (could not check)** or **(no attestation)**). Images from before 0.8.0 and images that are not `ghcr.io/ulm0/gonogo` are as before: confirmable by hand, never by auto-update.
