- **Room keys.** Flight Rules has ROOM KEYS: environment variables every agent of the room gets, such as the settings of Amazon Bedrock, set once instead of in each agent's Clearance fold. A value is saved (`room-keys.json`, mode 0600) and never shown again; an agent's own Clearance key of the same name wins; a Clean Room agent gets only the keys switched on for it ("Also in a Clean Room"), by name. A change asks for the password again and is noted in the Black Box by name. New: `GET /api/room-keys`, `PUT|DELETE /api/room-keys/<NAME>`. Applies at each agent's next start. Not seen in a browser; not run against a real AWS account.
