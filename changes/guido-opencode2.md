opencode 2.4.1 (the package @opencode/cli) replaces opencode 1.x: gonogo's plugin is rewritten on opencode's new plugin API (a folder with an index.js), every agent runs opencode --standalone with its own database in agents/<name>/opencode-data, the engine switch reads and finds sessions with opencode session export/list, and the Docker image installs @opencode/cli 2.4.1. opencode 1.x is no longer supported.
