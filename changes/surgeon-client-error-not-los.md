- **CLIENT ERROR instead of LOSS OF SIGNAL.** When the server answers but the page throws while it loads the room or opens the live connection, the page now shows "CLIENT ERROR" with the error message, instead of LOSS OF SIGNAL and an endless retry. A Copy details button copies the message, the gonogo version, the browser and the stack trace for a bug report, and the error also goes to the browser console. LOSS OF SIGNAL now means only that the server did not answer.
