- **`gonogo service`: run gonogo under systemd, launchd or OpenRC.** `gonogo service install [--now] [--home] [--host] [--port] [--pty-host]` writes a systemd user unit, a macOS LaunchAgent or an OpenRC init script that runs as you (it pins the paths of node and gonogo and your `PATH`), prints the commands that start it, and with `--now` runs them; `uninstall` and `status` complete it. It never runs as root and never runs `sudo`. Under a service, a reload and the Update key make gonogo exit and the manager starts the next one (`GONOGO_SERVICE`), and `gonogo reload` is allowed in a container that has its own manager. Docs: Run it as a service.
