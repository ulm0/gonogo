- **`gonogo service`: run gonogo under systemd, launchd or OpenRC.** `gonogo service install [--no-start] [--home] [--host] [--port] [--pty-host]` writes a systemd user unit, a macOS LaunchAgent or an OpenRC init script that runs as you, in your home (it pins the paths of node and gonogo and your `PATH`), and starts it at once, with no reboot (`--no-start` only writes the file); `start`, `stop`, `restart`, `status` and `uninstall` complete it. A step that needs root stops with the line to run again with `sudo` and your flags; the service runs as you, never as root. It will not start beside a foreground gonogo that holds the port. Under a service, a reload and the Update key make gonogo exit and the manager starts the next one (`GONOGO_SERVICE`), and `gonogo reload` is allowed in a container that has its own manager. Docs: Run it as a service.
