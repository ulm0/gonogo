- **A harness for the anchor engine on big repositories.** `node scripts/knowledge-bench.mjs` (and a weekly or by-hand workflow) makes a repository of 100,000 tracked files and runs the built engine on it: a repository over the 20,000-file cap is refused at once, a pattern that never ends is ended at 5 seconds, a file list over the cap reads "could not check", 20 runs at once never have more than 2 workers, and the memory stays bounded. Nothing changes for users.
