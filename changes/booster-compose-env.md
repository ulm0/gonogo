- **Docker Compose: the names you reach gonogo by now reach the container.** `compose.yaml` forwards `GONOGO_ALLOWED_HOSTS`, `GONOGO_PUBLIC_URL`, `GONOGO_TRUSTED_PROXY` and `GONOGO_CLIENT_IP_HEADER` from your shell or `.env` (before, only the overlays did, so `GONOGO_ALLOWED_HOSTS` in `.env` was ignored and every name but `localhost` got "forbidden host"; one you do not set stays unset). A browser that gets "forbidden host" now also reads what to set (`GONOGO_ALLOWED_HOSTS`, `--allow-host`, the `.env` and `docker compose up -d`); programs still get exactly `forbidden host`. CI starts the published image with `compose.yaml` and checks an allowed name is answered and another gets 403.
