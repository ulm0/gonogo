Autoscale (hire/fire PR5), off by default: with *Flight Rules > Hire on demand* set to dry run or on, FLIGHT's crew follows the Flight Plan. A task can name a position (only the boss and you can set it); when enough unassigned todo tasks name a position an agent of it is hired by rule, an idle boss-hired agent is stopped, and one stopped for long is removed. A dry run only says in the Downlink what it would do. It never touches an agent you hired, and acts at most once a minute.
