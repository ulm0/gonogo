- **A gonogo answers to its IP address with no configuration.** The front port accepts the IP addresses of the computer and its network as the `Host` (loopback, private, link-local, CGNAT such as Tailscale; names and PUBLIC addresses still need `--allow-host` or `GONOGO_ALLOWED_HOSTS`), so a container or a computer is reached from any device on the network at `http://<its address>:7777`; the login rules by the kind of address are unchanged. The 403 for a name that is not allowed says what to do. The `gonogo ready:` line carries the public address when one is named, and in a container a line on stderr says how to reach it.
- **A banner for an insecure setup.** `GET /api/exposure/findings` lists what is not safe (no login while reachable beyond this machine, plain http on a network address, a public IP address allowed, a public name with no second factor, the Docker socket mounted), each with what to do; the Director's own login can dismiss one for good (`POST /api/exposure/dismiss`), and a new finding shows again.
