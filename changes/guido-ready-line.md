- **A gonogo answers to its IP address with no configuration.** The front port accepts any IP address as the `Host` (names still need `--allow-host` or `GONOGO_ALLOWED_HOSTS`), so a container or a computer is reached from any device on the network at `http://<its address>:7777`; the login rules by the kind of address are unchanged. The 403 for a name that is not allowed says what to do. The `gonogo ready:` line carries the public address when one is named, and in a container a line on stderr says how to reach it.
