- **A new install keeps room main in `rooms/main/`.** On a fresh home the default room lives in its own folder, `<home>/rooms/main/`, like every other room; the root holds only what the supervisor owns (`auth.json`, `token`, `rooms.json`, `push.json`, `run/api.sock`). `rooms.json` records it (`main.home`). A home made before keeps main at the root, unchanged and unwritten: nothing is migrated. **Rolling back** to an older build on a home made by this one: the older build does not know `rooms/main/`, so it starts a new, empty main at the root and leaves `rooms/main/` untouched (go forward again, and remove the root's room files, to get the old main back). Docker needs no change: `GONOGO_HOME` is still the root.
