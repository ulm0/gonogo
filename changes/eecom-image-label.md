- **Fix: the Docker self-update could not accept any published image.** Every image through 0.11.0 carries the label `org.opencontainers.image.version` as `v0.11.0` (the git tag), and the update demanded `0.11.0`: the Update key and auto-update both answered "the image is version v0.11.0, not 0.11.0", and UNDO read the same label. The image workflow now labels the plain number, and gonogo reads one leading `v` as that number. **What this means for updating:** a gonogo up to 0.11.0 can update itself only to an image labelled the plain way, so the first update by key from such a container is to the next release; after that it works. Until then use `docker compose pull && docker compose up -d`.
