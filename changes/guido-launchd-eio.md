macOS: `gonogo service install`, `start` and `restart` no longer fail with "Bootstrap failed: 5: Input/output error" when launchd is still unloading the old job: gonogo waits for it to be gone (up to ten seconds), restarts it in place if it never goes, enables the label again if it was disabled, and otherwise prints what to check (the plist, the disabled list, the port, the log). `start` of a service that is already running says so; a gonogo started in a terminal that holds the lock is named (its pid) instead of loading a service that would only exit; `service status` says so too. Under Homebrew the service file names the stable `node` and `gonogo` (not the versioned Cellar folder a `brew upgrade` removes): run `gonogo service install` again to update an existing file.
