Docking 2, S2 (flow): a task handed to another station can be given back (`return`), withdrawn (`recall`), delivered and accepted (by hand or `autoAccept`), with deliverable links (pr, branch, commit, file, url; at most 5, checked, never fetched). The assignee is only a hint: a name that is no agent there gives an unassigned task and a message to that station's boss, marked as not from the Director. Per-station rules (`handoff: ask|allow`, `incoming: auto|off`, `autoAccept`, `staleHours`) are set from the Director's login. The boss gets a `task_handoff` tool; with `ask` the Director reads the whole text before it leaves. Incoming tasks reach the Downlink (a digest past 3 in 10 minutes), and a quiet accepted link tells the local boss once per period.
