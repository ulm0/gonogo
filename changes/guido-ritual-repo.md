- **A mission can take its closing checklist from its repo.** A mission has an optional `repo` (the git top level of a folder an agent of the room works in; it defaults to its lead's) and, when the repo has `.gonogo/ritual.md`, the checklist is copied from that file instead of the room's `ritual.md`. Lines from a repo are written by agents: they are cleaned, read only through the real path inside the repo, and labelled "from the repo". Only you set the repo and tick items. Going back to an older build drops `repo` at the first save of `missions.json`.
