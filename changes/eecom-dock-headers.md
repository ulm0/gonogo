- **Docking works through the rooms proxy again.** Since 0.10.0 the supervisor dropped every `x-gonogo-` header of a request, including the four a docked station signs its calls with (`x-gonogo-station`, `-timestamp`, `-nonce`, `-signature`). Two installs could pair (the pairing proof is in the body) but every later call (roster, message, hand-off, undock) was refused with "the call is not signed by a docked station", so the dock stayed `down`. The proxy now passes exactly those four headers on `/dock/` and `/uplink/` (a generic webhook's `X-Gonogo-Signature` was dropped the same way); every other `x-gonogo-` header, a forged `x-gonogo-director` or `-actor` included, is still dropped, and nothing changes for the page or a WebSocket. A webhook that sends only `Authorization: Bearer <secret>` still reaches the room without it (the proxy never forwards Authorization): sign it with `X-Gonogo-Signature` instead.
