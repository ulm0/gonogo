- **More key names are reserved, and a CA override warns.** A Clearance key or room key can no longer be named `ENV`, `ZDOTDIR`, `GIT_SSH`, `GIT_PROXY_COMMAND`, `GIT_EDITOR`, `GIT_PAGER`, `EDITOR`, `VISUAL` or `PAGER` (each makes a program run). `NODE_EXTRA_CA_CERTS`, `SSL_CERT_FILE` and `SSL_CERT_DIR` are still allowed, with a warning in the key forms: a proxy plus a CA you do not control can read the agent's TLS, Anthropic tokens included. A key already stored under a newly reserved name is not given to the agent: its name (never the value) is logged, a Downlink note lists it once, the key file is rewritten without it, and the agent and its other keys stay. **Going back:** an older build accepts these names again and gives the stored keys to agents.
