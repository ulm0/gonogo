- **Fewer CI runs per pull request.** The Docker image is built on a pull request only when it touches the Dockerfile, `packaging/docker`, `package.json` or the lockfile (main and tags still build it every time). The compose checks moved out of CI into the Compose workflow, which runs when a compose file changes and once a week. The Firefox and WebKit smoke runs weekly and by hand. The Docker self-update end-to-end test runs as the last job of a stable release's image build, which ends about 360 skipped runs a month.
