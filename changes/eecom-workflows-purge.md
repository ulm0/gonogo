- **Three CI workflows instead of 15.** `ci.yml` runs the checks, plus the browser smoke, the per-platform npm install, the service managers, the compose files and the Homebrew formula, each only when its own files change. `release.yml` also deploys the docs site; to publish a docs-only fix, run it by hand with `docs_only`. `image.yml` also runs the self-update end-to-end test after a stable release, and by hand. No workflow runs the Firefox/WebKit smoke, the screenshots, the flake detector or the knowledge bench any more: run them locally. No change for users.
