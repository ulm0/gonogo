- **Every room can have a project folder.** It is where the boss starts and the default Working directory of the hire form; without one a room works in the folder gonogo was started in, as before. Set it with `GET/PUT /api/project-folder` (owner login only, asks for the password again, written to the Black Box), `gonogo rooms add <id> --dir <folder>` or `POST /api/rooms {id, dir}`. A bad folder, and gonogo's own folders, are refused; running agents keep their folder.
