- **The edit form says which model and effort apply.** When an agent has none of its own, the Model and Effort fields now say what it starts with: the position's default or the room's (the Model field shows it as its placeholder and in the note; the Effort list's first line reads "room default (high)"). Before, only the room's model was named and the position's default and the room's effort were not, so the form looked blank for an agent that was running with them. An effort level the page does not know (from a newer server) stays selected, and a save that touched neither field no longer clears it.
