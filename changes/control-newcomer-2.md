- **Shift+Enter in a reply is a new line.** The reply box under a message (the inbox and the Party Line) sent the message on Shift+Enter. It is now a text box like the Brief box: Enter sends, Shift+Enter makes a new line, and the Enter that confirms an input-method composition sends nothing.
- **Staffing a console starts with three fields.** The staffing form now asks for the engine, a name and the working directory (it starts as the room's Project folder), with a plain line on each. Everything else (role of a seated position, model, effort, Clean Room, worktree, permissions, Payload, keys) is under MORE SETTINGS, folded; it opens by itself for an error, a bypass to confirm, or an agent that already has something set there.
