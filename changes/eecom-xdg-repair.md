- **Docker: root-owned files in `XDG_CONFIG_HOME` are given back at start.** `docker exec gonogo opencode models` (or `gh`, `aws`) runs as root and left root's files in a config folder bound outside the home, which the server could not write. The start now repairs that folder like the home (files with one link and directories that are root's, never across a mount, never through a symlink), and the docs say to use `docker exec -u node ...`.
