- **CI: the Docker self-update is run end to end.** After a release's image is pushed (and by hand), a workflow (`update-e2e.yml`, `scripts/update-e2e.sh`) starts gonogo from the previous release's image on the runner's own Docker, updates it to the new release through the real path (pull, `gh attestation verify` with the job's token, helper, health check), checks that the new version runs, then UNDOes and checks the old one runs again. No change for users.
