`gonogo service install` now takes the network flags of the server, `--allow-host` (one name, a comma list, or repeated), `--trusted-proxy`, `--public-url` and `--client-ip-header`, checks them as the server does and writes them into the launchd plist, systemd unit or OpenRC script, so a service can serve a name (docking by host name, a reverse proxy) without editing the file by hand. A reinstall replaces them. The server's own `--allow-host` and `--trusted-proxy` also take a comma list.
