- **Stop and start a room from the API.** `POST /api/rooms/<id>/stop|start`, `stop-all`, `start-all` and `PATCH { autostart }`; stop, stop-all, start-all and removing a room ask for the password again; an API key may not stop main or every room. Stops are refused while a poll, a Relief request, a move of main or an update is open; each action is audited to the log and main's Downlink, and alerts are held while main is stopped. The rooms page keys come later.
