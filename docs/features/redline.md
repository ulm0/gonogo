# Redline: the circuit breaker

gonogo stops a Claude agent by itself when it sees one of these: the same tool with the same input 5 times in a row (a loop), 8 failed tool calls within 2 minutes or 3 API errors within 10 minutes (an error storm), more than 15 messages to the same recipient within 10 minutes (a ping-pong), or a Propellant limit reached. A working agent gets an Escape, which interrupts its turn. The agent then shows `needs you` with a reason that starts with `redline:`, and its mail is held (`held: redline on <name>`) until you press **RESUME** (or `POST /api/agents/:name/resume`) or **STOP**. Typing into its terminal also ends the trip, as do a restart and a stop. Custom agents and engines without hooks are never tripped; a Gemini CLI agent is, by the loop and ping-pong rules (it has no hook for failed tools or API errors).

**Option.** `GONOGO_REDLINE=off` turns the automatic detectors off (loop, error storm, ping-pong). Propellant limits still stop agents. Default: on. See [Configuration](../reference/configuration.md#options).
