The update entry point, before and after

Before: the version is a link to the changelog, the strip shows only when a newer one is already cached (in room main), and CHECK NOW sits in the VERSION CHECK block of Flight Rules, thousands of pixels down. After: the version is a button; its popover says whether you are current and holds CHECK NOW and, when there is one, UPDATE.
