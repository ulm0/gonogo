UI semantic analysis: the mocks

Static before-and-after mocks for docs/ui-semantic.md. They are drawings in the app's own colours and shapes, not the app: nothing here is built. Open each one on a wide window.

  • The room view: the wall becomes a status strip; consoles and terminal in the first screen (1280 and 390 px)
  • The console terminal: size, expand, full screen, scrollback, copy, phone
  • Flight Rules: seven groups, rows that open in place, a search
  • Edit room: presets and a three-way choice instead of a grid
  • The rooms page: start and stop a room, all rooms
  • The update entry point: the version is a button
