Edit room, before and after

Before: a 12-column grid editor in which you drag and resize five blocks (A–F) by cells. After: a Layout popover with three presets, a three-way choice for each block, and the order of the seats. The grid editor stays, one level down, for the few who want to place blocks by hand.
